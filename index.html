Algebraic Fractions

Algebraic fractions are manipulated using the same rules as numerical fractions: factorise first, then cancel, multiply, divide, add or subtract as required.

Cancelling Common Factors

Factorise the numerator and denominator fully, then cancel any common factors.

Example

Simplify (x³ − 2x² − 9x + 4) / (x² − 36) when the numerator factorises to give a common factor with the denominator.

Solution

Factorise top and bottom fully, identify the shared factor (here, (x − 3) in the original worked example), and cancel it to leave the simplified fraction in fully factorised form.

Multiplying & Dividing Fractions

To divide, turn the second fraction upside down and multiply. Factorise everything first, then cancel common factors across the whole product before multiplying out.

Adding & Subtracting Fractions

Factorise each denominator first — finding the Lowest Common Denominator (LCD) before combining saves a lot of algebra later. Combine over the LCD, then expand and simplify the numerator only if it does not simplify further.

Equations Involving Fractions

Multiply both sides of the equation by the LCD to clear all denominators, then solve the resulting polynomial equation.

Example

Solve 1/(x−1) − 1/x = 1/(2x).

Solution

Multiplying through by 2x(x − 1) and simplifying leads to the quadratic x² + x − 2 = 0, which factorises as (x + 2)(x − 1) = 0, giving x = −2 or x = 1.

Tip: Always factorise denominators before searching for an LCD — never multiply unfactorised expressions together, or the LCD will be far larger than necessary.
02

Functions

A function is a mapping where every value of x in the domain gives exactly one value of y.

Notation

The following all describe the same function: y = x² − 3x + 7, f(x) = x² − 3x + 7, and f : x → x² − 3x + 7.

Domain, Range & Graph

Domain
The set of values that x is allowed to take — sometimes given explicitly, sometimes restricted by the function itself (e.g. √x requires x ≥ 0).
Range
The set of y-values actually produced by the function over its domain.
Example

Find the range of f : x → 2x − 3 with domain x ∈ ℝ: −2 < x ≤ 4.

Solution

Sketching the line over the domain shows the y-values run from −7 (excluded, since x ≠ −2) up to 5 (included, since x can equal 4), so the range is y ∈ ℝ: −7 < y ≤ 5.

Example

Find the largest possible domain and range for f : x → √(x − 3) + 1.

Solution

The expression under the root cannot be negative, so x − 3 ≥ 0 ⇒ x ≥ 3 is the largest domain. Sketching the graph shows it covers all y from 1 upward, so the range is y ∈ ℝ: y ≥ 1.

Watch for asymptotes: for a rational function such as f : x → (2x)/(x+1), the domain excludes the value that makes the denominator zero, and the range excludes the horizontal asymptote value.

Defining Functions by Restricting the Domain

Some mappings are not functions over all real numbers but become functions once the domain is restricted — for instance, x → √x is only a function once restricted to x ≥ 0, since negative inputs have no real output.

Composite Functions

For the composite fg(x), apply g first, then f. The range of g must lie within the domain of f for the composite to be defined. Note that fg and gf are generally different functions.

Inverse Functions & Their Graphs

The inverse of f, written f⁻¹, reverses the effect of f (this is not the same as 1/f). The graph of y = f⁻¹(x) is the reflection of y = f(x) in the line y = x.

To find the inverse of x → y:
(i) interchange x and y
(ii) rearrange to find y in terms of x
Example

Find the inverse of g : x → (2x − 5)/(x + 3).

Solution

Swap x and y, then solve for y by collecting all the y terms on one side and factorising — this yields g⁻¹ : x → (5x + 3)/(2x − 1). Note that f f⁻¹(x) = f⁻¹f(x) = x always.

Domain & Range of Inverse Functions

The domain of f⁻¹ equals the range of f, and the range of f⁻¹ equals the domain of f, because the inverse's graph is a reflection in y = x.

Tip: When a quadratic-type function has a restricted domain (e.g. x ≤ 3), check the reflection in y = x carefully to pick the correct sign (+ or −) when taking a square root while finding the inverse.

Modulus Functions

y = |f(x)|
Sketch y = f(x) first, then reflect any part below the x-axis up above it.
y = f(|x|)
Sketch y = f(x) for x ≥ 0 only, then reflect that part in the y-axis to complete the graph (since f(−x) = f(x) for any x value here).

Standard Graphs & Transformations

Know the shapes of y = x³, x⁴, 1/x, √x and the standard transformations:

TransformationEffect on y = f(x)
Translate by (a, b)y = f(x − a) + b
Stretch ×a in y-directiony = a·f(x)
Stretch ×a in x-directiony = f(x/a)
Reflect in x-axisy = −f(x)
Reflect in y-axisy = f(−x)
Order matters: e.g. y = 3x² + 6 is a stretch ×3 followed by a translation of (0, 6) — but to apply the translation first, you must rewrite as 3(x² + 2), giving a translation of (0, 2) followed by the stretch. Combined transformations don't commute unless rewritten correctly.

Sketching Curves

Always show: coordinates of axis intercepts, and the equations of any asymptotes (drawn as dotted lines).

Trigonometry

Sec, Cosec & Cot

cosec x = 1/sin x

No calculator buttons: convert sec/cosec/cot equations into sin, cos, tan form before using a calculator — there are no direct buttons for the reciprocal functions.

Finding Exact Values

Build unknown angles from known exact values (30°, 45°, 60°) using the compound angle formulae — e.g. cos15° = cos(45° − 30°) expands to give an exact surd answer.

Proving Identities

Work on one side only (usually the LHS) and manipulate it algebraically until it matches the other side. Never alter both sides simultaneously.

Eliminating a Variable from Parametric Equations

Example

Eliminate θ from x = secθ − 1, y = tanθ.

Solution

Using sec²θ − tan²θ = 1 and substituting secθ = x+1, tanθ = y gives (x+1)² − y² = 1, which rearranges to y² = x² + 2x.

Solving Trig Equations

Choose whichever identity simplifies the equation to a single trig function. Equations involving sums/differences of sines or cosines (like sin3x − sin5x = 0) are solved by converting to the product form first, then setting each factor to zero in turn.

R cos(x ± α) and R sin(x ± α)

Used to rewrite expressions like a cos x ± b sin x as a single trig term. There are four standard forms — choose the one whose sign pattern matches the expression, so that R stays positive and α stays acute.

R cos(x + α) = R cosx cosα − R sinx sinα
R cos(x − α) = R cosx cosα + R sinx sinα
R sin(x + α) = R sinx cosα + R cosx sinα
R sin(x − α) = R sinx cosα − R cosx sinα
Example

Solve 12 sinx − 5 cosx = 6 for 0° ≤ x ≤ 360°.

Solution

Since the sinx term is positive and the cosx term is negative, use R sin(x − α). Equating coefficients gives R = 13, α ≈ 22.62°, so 12sinx − 5cosx = 13 sin(x − 22.62°). Solving 13 sin(x − 22.62°) = 6 gives x ≈ 50.1° or 175.1°.

Tip: Once in the R sin/cos(x ± α) form, the maximum/minimum value of the whole expression is simply ±R, occurring when the trig term equals ±1 — useful for max/min value questions without further differentiation.

Exponentials & Logarithms

Natural Logarithms

e ≈ 2.7183. Logs to base e are natural logarithms, written ln x (i.e. log_e x). The graphs of y = eˣ and y = ln x are reflections of each other in y = x, since they are inverse functions.

Transforming exponential graphs: for y = e^(ax+b) + c, rewrite the exponent to isolate the stretch and translation — e.g. e^(2x+3) = e^(2(x + 3/2)) shows a stretch ×½ in x, then a translation, then the +c shifts vertically.

Solving Equations of the Form e^(ax+b) = p

Example

Solve e^(2x+3) = 5.

Solution

Take ln of both sides: 2x + 3 = ln5 ⇒ x = (ln5 − 3)/2 ≈ −0.695.

Example

Solve ln(3x − 5) = 4.

Solution

Raise both sides as a power of e: 3x − 5 = e⁴ ⇒ x = (5 + e⁴)/3 ≈ 19.9.

Differentiation

P3 builds on the chain, product and quotient rules from P2 by applying them to eˣ, ln x, and the trig functions, and introduces differentiation with respect to a different variable.

Chain Rule — Reminder

dy/dx = dy/du × du/dx

Differentiate the outer function with respect to u, then multiply by du/dx.

Derivatives of eˣ and ln x

eˣeˣ

Example

Differentiate f(x) = ln3x − ln x⁵.

Solution

Simplify first using log laws: f(x) = ln3 + lnx − 5lnx = ln3 − 4lnx, so f′(x) = −4/x.

Derivative of aˣ

y = aˣ ⇒ dy/dx = aˣ ln a
Know this proof: take ln of both sides of y = aˣ to get ln y = x ln a; differentiating implicitly gives (1/y)(dy/dx) = ln a, so dy/dx = y ln a = aˣ ln a.

dy/dx = 1 ÷ (dx/dy)

Useful when x is given as a function of y and is easier to differentiate that way round.

Example

If x = sin²3y, find dy/dx.

Solution

Find dx/dy first: dx/dy = 6 sin3y cos3y. Then dy/dx = 1/(6 sin3y cos3y), which simplifies to ⅓ cosec6y.

Combining the Chain, Product & Quotient Rules with Trig/Exp/Log

Example

Differentiate y = x² × cosec3x.

Solution

Using the product rule with u = x², v = cosec3x: dy/dx = −3x²cosec3x·cot3x + 2x·cosec3x.

Example

Differentiate y = tan2x / 7x³.

Solution

Using the quotient rule and simplifying the result over a common power of x gives dy/dx = (2sec²2x)/(7x³) − (3tan2x)/(7x⁴).

Numerical Methods

Locating the Roots of f(x) = 0

A quick sketch of y = f(x) gives a rough idea of where the roots lie. If f(x) is continuous on [a, b] and changes sign between x = a and x = b, then a root lies in that interval.

The Iteration xₙ₊₁ = g(xₙ)

Example

Show a root of f(x) = x³ − 8x − 7 = 0 lies between 3 and 4, rearrange as x = ∛(8x+7), and iterate from x₁ = 3.

Solution

f(3) = −4, f(4) = +25 — a sign change confirms a root in [3, 4]. Iterating xₙ₊₁ = ∛(8xₙ+7) from x₁ = 3 gives x₂ ≈ 3.1414, x₃ ≈ 3.1791, x₄ ≈ 3.1891, converging towards α ≈ 3.19 (3 s.f.).

Justifying accuracy: to confirm a root is correct to 3 s.f. (e.g. α = 3.19), evaluate f(x) at the interval boundaries either side of the rounding point (e.g. f(3.185) and f(3.195)) and show a sign change — this proves the root lies in that narrow interval.

Conditions for Convergence

For the iteration xₙ₊₁ = g(xₙ) near a root x = α:

Condition on g′(α)Behaviour
0 < g′(α) < 1Converges, staircase pattern (no oscillation)
−1 < g′(α) < 0Converges, oscillating/cobweb pattern
g′(α) < −1 or g′(α) > 1Diverges
